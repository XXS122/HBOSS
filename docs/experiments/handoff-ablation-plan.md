# 技能切换对照实验

目标：判断技能 2 → 3 失败与机械臂位置、速度及切换前等待的关系。冻结已有模型，不训练。

1. 按 MuJoCo 关节名称读取地址，检查两个环境的状态布局、复制结果和控制器初始化。
2. 先收集 20 个前序技能成功且后续技能尚未成功的终止状态；每个状态使用 3 个评估 seed，比较六组。
3. 六组：不复位、仅位置复位、仅速度清零、两者同时、保持当前末端位姿等待停止、现有固定切片复位。
4. 后续技能统一最多 400 步；等待最多 40 步。等待超时计失败。记录前序目标是否保持、后续成功率和耗时。
5. 本地用模拟对象测试状态修改和统计逻辑；实际 MuJoCo 控制与图像恢复必须在服务器小规模验证。

本实验采用统一的控制器初始化规则，比较物理状态干预；不宣称复现旧实验的绝对成功率，也不等于同一个环境内连续控制。三个评估 seed 复用同一组状态，不是 60 个独立场景。
