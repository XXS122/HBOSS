# 面向当前BOSS代码的最低可行实验方案

**全部为建议设计，尚未实现或运行。** 原始BOSS协议是主线，无重置是单列扩展；当前任务不修改任何算法和代码接口。

## 1. 先锁定可复核的基线

执行任何新训练前，保存当前代码文件哈希、环境版本、论文/网站版本、模型/数据来源与校验值。由于当前目录不是Git仓库且缺少根级资源/权重，不能声称已具备即刻复现条件。

必须先查清[项目画像§5](01-boss-project.md)的配置/数据问题：实际传入的seed，checkpoint配置是否覆盖CLI；SequentialEnv的seed传递；示范过滤是否使用旁路成功索引；重放state和观测是否对应；训练/验证是否真的按轨迹分开。这是将来实验的前置检查，不在本次研究中顺手修代码，也不据此断言原论文有相同运行问题。

| 阶段 | 最低产物 | 通过条件 |
|---|---|---|
| A 原协议核对 | 1条单技能和1条链的完整事件日志 | 能从日志重建技能切换、reset前后状态、成功判据和实际seed；无需先追求论文同分 |
| B 原基线评测 | 固定checkpoint的原任务/CH1/CH2/CH3结果 | 分母、预算、任务映射一致；资源和运行失败单列 |

| E 无reset扩展 | 独立命名协议及桥接对照 | 原基准结果保持独立，真实环境动作/状态写入明确区分 |

## 3. 配对干预设计

取同一基础边界快照，在共享随机条件下运行下面分支；所有分支使用同一后继、同一动作预算和判定器。

| 分支 | 改变内容 | 要回答的问题 |
|---|---|---|
| N 自然交接 | 前驱真实执行产生的终态，随后按原协议reset | 真实分布中的后继条件成功率是多少 |
| V 仅观测 | 同一物理状态和动力学，只改变明确可分离的渲染/观测 | 策略对纯视觉差异是否敏感 |
| P 物理入口 | 明确改变可达性/抓持/接触或前置条件 | 是物理不可执行还是视觉失败 |
| R 保持义务的恢复 | 恢复部分视觉/机器人状态，同时检查仍有效义务 | 在不撤销任务进度下能否改善 |
| U 无约束恢复诊断 | 允许回到熟悉状态，但计量其是否破坏义务 | 更高“后继成功”是否靠取消前序成果获得 |

U仅是仿真反事实诊断，不作为合格部署方案。V的外观扰动并不等价于全部BOSS谓词变化：一旦移动对象可能改变碰撞、质量或支撑，就不能称纯视觉干预。此时必须验证动作可行性及动力学影响，或降为匹配比较并保留混杂说明。

义务由任务的生产者—消费者/最终目标定义。例如暂时holding会在合法place后消解，不能把松夹爪一律判为失败。分别记录“已经发生过某技能成功”“当前关系仍成立”“最终任务要求已满足”。保护历史所有谓词会错误惩罚正常执行。

物理可执行性的oracle也有边界：一个控制器失败不足以证明不可达。可用经过验证的参考轨迹/规划找到成功作为可执行正证据；未找到解标为未知而非证明无解。标签错误应人工抽核，报告一致率及争议处理。

## 4. 训练、验证与测试划分

原任务44、CH1单谓词44、CH2双/三谓词各44、CH3十条三技能链各自报告，不合成单一主分数。增加未见组合是独立扩展，必须公开任务清单，不能拿测试结果选任务。

建议采用外层按谓词组合或技能配对留出、内层按基础rollout/源示范分组的划分：

- 同一示范的原始、RAMG和所有反事实后代属于同一split；同一初态和重放种子产生的变体也不能跨split。
- 模型、门控阈值和一致性权重在独立验证组合上选择；测试集固定后只评估，避免“每epoch看测试取最好”。
- 要检验**组合**泛化，应保证测试组合中的单个谓词/技能可在训练中出现，但联合组合未出现；另外报告完全新实体/外观，其难度不同。
- CH3仅10链，不能由20rollout或重复seed宣称大量独立组合。按链/场景做区组统计；有效链数不足时保留探索性结论。
- CoRe类检测bank、成功校准轨迹及可执行性预测训练集也受同样分组规则约束；仅阈值验证seed不同并不足以排除共享实例。

建议从每链总计20次、跨3个实际独立评估seed分配7/7/6次的诊断开始：10链共200条整链rollout，三技能链至多400个成功前缀自然边界。再依据独立pilot的置信区间和方差确定扩大预算。这个数目是可行性起点，不是统计功效已足够的承诺。I2训练至少3seed；评估seed与训练seed分开，报告每个seed及宏平均。

## 5. 对照与消融

| 问题 | 最低对照 | 必须固定或记账 |
|---|---|---|
| I1审计有没有增量 | 原策略；等预算重试；仅后继打分；仅义务检查；两者组合；oracle审计 | 同技能、同judge、同快照族、同环境步和恢复次数 |
| I2是否只是多数据 | 原BC；RAMG；阶段增强；＋真实交接数据；＋普通成功过滤 | 总新增rollout、成功示范数、更新步、骨干与相机 |
| 门控是否必要 | 无门控一致性；门控无负例；完整门控；oracle门控 | 同正负比例、验证预算、参数量；失败负例只进门控监督 |
| 对齐对象是否合理 | 表征/动作代理分别作预定义消融；不一致就拒判 | 共享动作采样噪声，说明多模态假设，不事后挑最好 |
| 视觉感知是不是瓶颈 | 自动mask/视觉门控 vs 真值mask/状态标签 | oracle仅诊断上界；不得混成RGB部署成功 |
| 成果是否被撤销 | 所有恢复记录必要谓词；允许/禁止撤销诊断 | 合法消解不处罚；记录修复移动对象集合 |
| 无reset物理扩展 | 直接切换；几何桥接；DeCo/SPIN启发连接；真实CoRe式恢复 | 同物理动作预算；状态写入单列oracle，不算实体执行 |

Foresight式后继评分和SCaR式训练可作为机制对照，但不是最低BC实验必须一次全部复现的条件；它们额外RL和标签预算大，应在资源充足时另表比较。改编实现必须标注“启发式适配”，不能冒用原文分数作为本地对照。

## 6. 指标的精确定义

| 指标 | 定义/分母 | 用途 |
|---|---|---|
| 原子成功率 | 指定原始或修改分布中成功episodes / 全部有效episodes | 不只报受影响任务；场景宏平均与计数同时给 |
| 自然边界后继率 | 前缀成功后，该位置后继成功次数 / 到达该边界次数 | 条件分母随位置变化，前驱失败不能悄悄丢弃整链统计 |
| 配对干预后继率 | 固定边界数据集上各分支成功数 / 同一快照数 | 避免不同方法到达不同边界的幸存者偏差 |
| 历史整链成功 | 所有阶段按协议先后完成的episode比例 | 与原BOSS口径保持可比 |
| 义务有效整链成功 | 历史整链成功且所有仍有效最终义务满足 | 新增扩展指标，不能替换旧指标却沿用旧名称 |
| 义务破坏率 | 活跃期间由真变假且无合法消解的谓词事件 / 被监测活跃谓词事件 | 同时给至少一次破坏的episode比例，免事件数稀释 |
| 干预门控误判 | 无效样本被接受比例；有效样本被拒绝比例；拒判比例 | 不仅报告总体accuracy；分别按接触/支撑/遮挡等类别 |
| 预测校准 | Brier、预定义分箱ECE、风险—覆盖率曲线 | 高accuracy不代表成功概率可信；阈值只用验证集 |
| 原任务损失 | 新策略原始分布成功率−原基线成功率（pp） | 检查“抗OSS”是否牺牲基础控制 |
| 成本 | 新示范数、全部采样/失败回放步、训练GPU时、推理/恢复墙钟、LLM调用与token | 不只算成功轨迹或handoff后步数 |

原始RPD另报逐任务分布和受影响子集均值；基线为0时NA。乘积 \(U=\prod_i p_i^0\) 名为乘积参考；如用 \((U-p_{chain})/U\)，明确这是本实验选择的损失符号，U=0为NA。不把U当无条件理论上界。

置信区间优先按任务/链与独立seed分层bootstrap；同一基础快照多个干预不能当独立样本。单任务二元率可附Wilson区间。链少时给原始计数/逐链结果比一个过度精确的总体p值更诚实。用于方向筛选的最小有意义增益、允许原任务损失和最大成本在pilot后、最终测试前锁定；不在无方差资料时编造功效分析。

## 7. 资源与停止规则

I1首先依赖数据、权重和可重放仿真；I2增加门控/BC训练；OpenVLA扩展需单独核显存和动作分布接口；无reset增加控制器适配、碰撞模型与连接器训练。论文使用的8×4090、H200、8×V100等是作者配置，不能当作本项目最低要求。

若配对状态无法可靠恢复、义务定义争议大、标签不可识别或验证分布被泄漏，应停止效果比较先修评测；若简单同预算数据基线已覆盖收益，否定复杂门控必要性。若新方向被后续论文完整覆盖，保留复现/适配价值但撤销方法新颖性。
