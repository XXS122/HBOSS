# 补充新颖性复检：成果保持、累积约束与视觉交接

复检日期：2026-09-11。此文件补充主报告，不增加20篇候选或10篇精读的名额。目标是主动寻找能够否定“保持前序成果的视觉handoff”这一笼统创新的证据。

## 结论

**撤销“首次把前序成果保持、累积谓词约束和handoff决策结合”这一宽泛新颖性表述。** BATON已做面向剩余计划的交接契约；MoMaStage v2明确在恢复时保留已完成子任务并传播累积机器人状态；Inverse Manipulation已把交接时成立的谓词作为后续残差学习的保护约束。更早的因果链接规划也已处理事实的生产、消费与中途破坏。

建议将BOSS方向首先定位为**可归因的交接评测与数据贡献**：把必要成果的保持、后继物理可执行性及视觉分布偏移分开测量。在获得新实验证据前，不将视觉检测器加义务集合包装成独立新算法。

来源：[官方元数据](https://arxiv.org/abs/2603.08383)、[v2 HTML](https://arxiv.org/html/2603.08383v2)、[当前PDF，首页确认为v2](https://arxiv.org/pdf/2603.08383)、[作者项目页](https://chenxuli-cxli.github.io/MoMaStage/)。PDF9页，已读§I–V、表I–V；没有附录。固定版本PDF入口曾返回工具错误，当前PDF成功且版本已核对。

**分析者判断**：文中的“保留成果”不等于对任意对象关系提供形式化不变量证明。Eq.4验证范围由三元机器人状态决定；作者也明确指出抽象之外的物理限制。因此应承认其系统贡献，同时把BOSS拟议增量限定为**不同失效源的独立测量与特定关系的可审计标签**。本文规划指标要求严格匹配真值序列（§IV-A），也不应作为多样合法计划的完整有效性标准。

### 新发现的直接反证：Inverse Manipulation

[官方元数据](https://arxiv.org/abs/2606.05248)、[v1全文](https://arxiv.org/html/2606.05248v1)、[v1 PDF](https://arxiv.org/pdf/2606.05248v1)。首次2026-06-03，当前v1；作者Yildirim、Rauso、Caccavale、Finzi；预印本。本文为复检补充，未替换原20候选。

§Method，PDF p.2–3：已满足逆目标谓词构成fence集合，剩余谓词构成active集合；Eq.4对fence破坏施加单侧惩罚，再训练SAC残差。§Implementation Details：12维高层状态输入；表1–2：PushCube单任务、10种子，1cm成功90%。§Limitations：手工谓词和参数、脚本原语、单任务族。

**判断**：任务目标是逆操作，与BOSS向前组合不同；但“交接时区分已满足与待达成谓词，并约束后续控制不要破坏已满足者”已被直接实现。不能用目标不同忽略其机制重叠。其有限样本与软惩罚不构成保持保证；换为图像输入可作工程扩展，需额外证明为何现有视觉谓词方法不足才能提升为方法贡献。

### 更早的概念反证与邻近领域

- [Planning by Rewriting，JAIR作者托管正文§2.1](https://www.cs.cmu.edu/afs/cs/project/jair/pub/volume15/ambite01a-html/node7.html)：因果链接记录生产者、命题和消费者，干扰该命题的动作构成威胁。因此“只保护尚未消费的已完成事实”与经典规划义务高度重合，不能声称新形式化。
- [Concurrent Plan Recognition and Execution for Human-Robot Teams，ICAPS原文](https://cdn.aaai.org/ojs/13672/13672-40-17190-1-2-20201228.pdf)，算法2：因果链接和威胁消解已涉及执行选择及恢复事实；本轮只定向核查该机制，未纳入精读集合。
- [Self-Evolving Just-In-Time Memory，2607.16247v1](https://arxiv.org/html/2607.16247v1)，§4.1–4.4、附录A：已使用关系状态记忆与时序义务，并安排与任务进展相容的干预。本轮只核查相关章节，未完成其全面实验审计；不能凭它否定全部handoff增量，也不能无视“progress-preserving”在邻域已有使用。

## 建议保留的最窄、可验证增量

建议研究问题改为：**在BOSS的观测偏移评测中，若一种衔接方法使后继成功率升高，这一改善究竟来自视觉鲁棒性提高、物理初态修复，还是撤销了仍需保持的先前成果？现有成功率是否区分这些机制？**

这是评测假设，不是已经观察到的BOSS缺陷。需要先检查BOSS当前最终成功判定是否已覆盖全部任务义务；若已覆盖，则新增贡献只能是机制分解、干预数据和诊断敏感性，不能称修复了“虚假成功”。

最小可行设计：

1. **固定手工链及义务定义**：逐链标注必要事实、产生事件、消费者或最终目标、生效/结束事件、允许的关系替换。不能保护全部历史谓词；合法放下物体必然撤销holding，不能判为成果丢失。该定义是基于经典因果链接的任务标注协议，不称新规划理论。
2. **先离线、再训练**：从现有CH3采集边界快照，记录BOSS重置前后状态。用仿真谓词作离线审计真值；对视觉检测器单独评估，禁止真值泄漏给视觉策略。义务集合按任务结构提供，与从RGB判断事实是否成立分开。
3. **两条实验线**：主线保留原BOSS reset；独立扩展才取消reset，并明确机器人位姿、物体位姿及速度的干预范围。不能将两者混为同一基准分数。
4. **干预可识别性**：纯视觉分支需同物理快照、只改变观测，验证转移动力学与必要事实不变；物理分支需明确哪项可执行条件受破坏。若只能更改场景物体位姿，需检查碰撞/接触影响，并降称匹配条件比较，而不是纯视觉因果干预。符号“无关”并不自动证明动力学无关。
5. **指标与对照**：同后继、同预算、配对随机种子；报告链成功、后继条件成功、仍有效义务破坏率、合法消解误报率、视觉readiness校准和新增时延。对照至少包括原策略、仅后继成功打分、仅义务检查、二者结合；oracle义务仅作诊断上界。
6. **数据拆分**：按基础快照/rollout族和谓词组合分组；同一快照的变体不可跨训练测试。保留未知组合测试及原任务能力回归。先审核可定义义务的链数，若十条链缺少足够反例，不扩大声称范围。

**能够否定该方向的结果**：原BOSS最终判定已完全覆盖义务且额外日志不改变方法排序；保留义务的检测没有区分度；收益只由增加重试预算产生；在相同后继成功率下，“义务检查”无增益；视觉分支无法和物理变化隔离。出现这些结果时，应缩为复现与分析报告，放弃算法创新宣称。

## 证据等级与建议措辞

| 判断 | 等级 |

| 前驱末态与后继可靠性相关；局部技能成功不充分 | 多篇独立实验支持问题动机，可E3；不代表拟议算法有效 |
