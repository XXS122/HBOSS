# 方法、数据与实验比较矩阵

单位和信息条件不同的结果不排序。下表中的V指视觉，S指真实/估计物体状态；使用S训练或规划的结果不能直接作为BOSS RGB部署成绩。NR表示原文未明确报告，不表示零。详表、作者短引及附录定位在对应证据卡。
