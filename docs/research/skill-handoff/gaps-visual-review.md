# 视觉干预有效性与技能阶段相关性：独立新颖性复检

复检日期：2026-09-11。范围：2024-01-01 至检索日。RoCoDA v2 已阅读本地全部 7 页；CoRe 在复检中发现后进入最终候选 P15，并另完成[全文证据卡](/E:/code/BOSS-main/docs/research/skill-handoff/cards/P15-core.md)。其余补充近邻核对官方全文的方法和相关附录，未按十篇证据卡标准完成全面实验审计。本文中的新方法均为待验证假设。

**结论：必须撤销“阶段因果结构”“成功验证增强”“学习局部相关性”“保护累计成果”“动作兼容的反事实探测”这些独立的新颖性说法。** 本次检索范围内尚未发现充分覆盖的最窄组合是：在 BOSS 真实技能交接分布上，以接触/支撑变化和累计谓词保护的成对仿真验证监督可学习门控，仅对验证有效的干预施加后继视觉策略一致性，并显式训练/评估不应不变的负例。该组合仍可能只是已有方法的组合工程，整体新颖性仅 **N1**，预期效果 **E0**。

## 2. 最关键近邻：RoCoDA v2

[官方版本页](https://arxiv.org/abs/2411.16959)，[v2 PDF](https://arxiv.org/pdf/2411.16959v2)，[作者项目页](https://rocoda.github.io/)。首次公开 2024-11-25，所读 v2 为 2025-05-20；ICRA 2025，另有 [IEEE 正式记录](https://ieeexplore.ieee.org/document/11128694/)。本地全文：[P20.pdf](/E:/code/BOSS-main/docs/research/skill-handoff/sources/P20.pdf)、[P20.txt](/E:/code/BOSS-main/docs/research/skill-handoff/sources/P20.txt)。下列页数为 PDF 页序。

**已有阶段因果结构。** §III-A p.3 给出局部因果模型，双臂交接过程中图结构会变；§IV-A pp.3–4 用夹爪开合启发式划分阶段，为阶段/机器人配置图，合并依赖关系后形成分区，从其他轨迹的相同因果阶段共同抽取相关变量。模拟器拼接状态并重渲染观测。不是整条轨迹共用一个静态“无关物体表”。依赖图和阶段事件主要由先验规则给定，未描述用反事实成功/失败标签学习图。

**已有有效性过滤，但应准确限定作用阶段。** §IV-B p.4 中 SE(3) 变换同时调整物体姿态和动作，插值连接轨迹，执行后仅保留成功子任务，失败轨迹丢弃。不能写“RoCoDA 不验证增强有效性”。其 causal splicing 主要依赖阶段图正确；文中未明确逐对检验目标等价、接触序列、支撑结构或下游累计成果，不能把 SE(3) 成功过滤误写成已覆盖这组更强条件。

**未发现显式成对视觉/策略一致性损失。** §IV-C p.4 的视觉增强为裁剪、颜色扰动、噪声；颜色决定目标的任务不使用 color jitter，已经体现“语义相关时不应增强”。模型训练仍为下游 ACT 行为克隆；群不变性和因果不变性是增强依据，并非一项对原观测/干预观测的预测 KL 或特征距离损失。

**实验证据的适用界限。** Table I p.5 的三任务完整方法成功率依次为 71.3±1.25、15.7±2.05、49.3±1.25；去掉 Visual+Causal 为 58.7±3.09、11.3±0.47、45.0±1.63（百分比，三种子，取训练中最佳检查点；数值需结合原表任务列阅读）。Table III p.6 的单个 LIBERO-Object 任务在 distractor 测试中 RoCoDA 为 99.3%，MimicGen 为 99.0%。这不是 BOSS 的 CH1–CH3 或未见技能组合；近乎饱和的单任务实验不能直接支持交接门控有效。

**作者声明与分析者推断分开。** 作者在 p.5 讨论稳健性与精度的取舍；p.6 报告在 transit 阶段增强带来再抓取行为。本文关于“没有累计谓词验证/没有成对一致性项”的结论来自所读方法和目标函数核对，是本次审计结论，不冒充作者自认不足；未找到单独 limitations 节。

## 3. 补充反例：不能忽略的 2024–2026 方法

**CAIAC，ICML 2024。** [官方全文 v2](https://arxiv.org/html/2405.18917v2)，首次 2024-05-29，v2 2024-12-12。§4.1–4.3 通过状态条件互信息学习动作对对象的局部影响，交换源/目标中共同不可控变量，可对时间窗口取交集。其关键假设忽略对象间作用；§4.3 明确承认拼接可能改变因果机制，但额外影响检测是 OOD 查询而不可靠，故实际不检查。**对应差异：**真实仿真干预验证可绕开这一特定缺口；学习局部相关性本身早已有之，支撑/碰撞任务尤其不能沿用其独立性假设。

**AFP，CoRL 2026 accepted。** [官方全文 v2](https://arxiv.org/html/2607.10655v2)，首次 2026-07-12，v2 2026-09-07。§3.3–3.4 用标注任务相关掩码监督注意力分布，L2 辅助项配 PCGrad，避免辅助梯度与动作梯度冲突；§5 明示从交互、时间一致性、反事实场景变化或策略失败推断相关性的未来方向。**对应差异：**这是人工相关性监督和优化约束，未验证成对场景的物理作用等价。但“动作不受损的相关性正则化”与“交互学相关性”的宽泛提法都不能独占。

**CoRe，2026-08-14 v1 公开预印本。** [官方全文](https://arxiv.org/html/2608.14822v1)。Methodology Eq.(1) 已要求累计子目标保留；Phase-Aware Recovery Anchoring 选择无接触锚点。Probe-Based Minimal Restoration Eq.(7) 比较反事实恢复子集与全部恢复的手臂轨迹差异，确定可不恢复的物体；目标物体、近邻和占用目标区域者有强制恢复规则。虚拟 rollout 在接触前终止。**对应差异：**已直接覆盖成果保护、阶段检查和动作等价探测，但用于冻结 VLA 的推理时恢复，未学习训练期一致性门控；它也不验证接触后动力学。不能将其“接触前”约束误说为完整物理等价保证。

**Embodied Interpretability，ICML 2026 accepted。** [官方全文 v2](https://arxiv.org/html/2605.00321v2)，首次 2026-05-01，v2 2026-06-10。§4.1 的 ISS 比较遮蔽前后动作分布，固定各向同性高斯假设下用动作 MSE 代理 KL。它测量策略依赖什么，不能证明环境中什么真正无关；也说明“用动作变化判断视觉因果影响”不是空白。本文不采用其预测差异作为物理标签的充分条件。

另检得 [AGRA](https://arxiv.org/html/2606.12217v1)（2026-06-10），属于动作条件世界模型中的表征对齐，已读相关方法段，未见相同 RAMG 成对标签方案。[CAGE-SGG](https://arxiv.org/abs/2604.22274)（2026-04-24）已在场景图生成中讨论移除必要证据和无关扰动的反事实检验；这里只完成元数据/摘要核对，不能作为已完成最近邻全文比较。上述两项是边界提醒，不用于宣称本方案优越。

## 4. 唯一暂可保留的最窄假设

**H：**在同等交接采样量和训练预算下，使用已验证的目标/短时动力学/累计成果条件监督阶段门控，比 RoCoDA 式阶段图增强加普通成功过滤，更少把实际相关谓词错当作无关，并提高 BOSS 未见谓词组合下的后继成功率；效果不是来自额外 rollout 数据或更好的单技能策略。

这是分析者提出的可证伪假设。暂定 **E0/N1**；视觉组合偏移问题已有实验支持，不可把问题层面的 E3 自动赋给这个新机制。针对 RoCoDA、CAIAC、AFP、CoRe 的已覆盖结论有直接原文依据；整体 N1 是因为最新近邻的引用/被引网络和其他形式化不变性方法尚未穷尽，不能声称已完成全领域新颖性证明。

建议把研究对象写成“交接分布中的干预有效性学习”，不写“提出阶段因果图”或“首个保护成果的反事实方法”。所需监督是在训练期仿真中可得的特权状态；部署时若要求 RGB-only，必须单独报告从视觉估计门控的性能，不能把 oracle 状态门控收益当部署收益。

### 标签和目标必须避免的循环论证

1. 当前策略在两张图上动作相同，可能是“两边都错”；因此动作相同不能独自标成有效干预。语义目标相同也不保证可执行动作集合相同。
2. 对同一有效目标，动作可能多模态；不应要求两个任意成功轨迹逐帧相同。先定义允许的局部后果/接触约束，再决定是否适合对齐动作分布、任务表征或价值，三者不是可互换目标。
3. 在共享初态、机器人状态与仿真随机条件下，仅修改指定谓词，验证其后续结果。交接样本来自真实前驱 rollout；必须把原协议重置机械臂后的交接和无重置扩展分开。
4. 正例要求目标可达、短窗接触/支撑没有不可接受变化，并保留显式需要维持的前序谓词；负例保留碰撞、支撑改变、遮挡关键目标及破坏下游必要成果的情形。未知样本应拒判，不能默认无关。
5. “所有已完成谓词永久为真”可能与合法后续技能冲突。保护集应来自当前链必须维持的成果和未来前置依赖；允许被后续任务明确撤销的谓词不能硬保留。

### 最低可行否定实验

先固定 BC 骨干、训练示范和链顺序，原始任务、CH1、CH2、CH3、未见谓词组合分别评估。对照包括 RAMG、RoCoDA 式阶段增强、阶段增强加同预算真实交接数据、阶段增强加 rollout 成功过滤、无门控一致性、门控无负例、完整门控；可学习门控和 oracle 门控分开。CoRe 更适合作为推理恢复近邻，若实现应单列其恢复成本和协议，不与纯训练正则法混为等资源排名。

主指标是每个链位置的后继条件成功率与二值整链成功率；另报无效不变性误判率、必须保护谓词的破坏率、错误拒绝有效干预率、原任务性能损失、新增仿真步数和训练/推理耗时。数值阈值用独立验证组合确定，不用测试组合调门控。

若同预算“阶段增强+交接数据+普通成功过滤”达到相同提升，或收益仅来自额外数据，门控机制假设不成立；若视觉门控误删支撑/碰撞线索使组合成功率下降，应否定当前标签/目标；若 oracle 有效而视觉估计无效，只说明监督上界，不能宣称可部署方法成功。
