# BOSS Skill Handoff：近年文献、证据审计与研究方向

**结论：BOSS 最适合先研究“后继技能仍可执行，但前序留下的场景使视觉策略失效”。它的原始串联协议重置机械臂，不能直接回答完整物理交接问题。** 本次调研选出20篇候选，完成10篇核心全文证据卡，并对最接近的反例补充阅读全文或定向章节。检索截止2026-09-11，窗口2024-01-01起，优先最近24个月。BOSS不占名额。

研究包只完成文献研究、代码静态审计与实验设计；**没有修改算法接口、运行训练或复现实验**。论文事实、作者声明、分析推断和拟议假设在各证据卡中分开。所有效果数字均是原文报告，除明确标注的算术重算。

## 1. 当前项目与研究问题

本地代码对应 *BOSS: Benchmark for Observation Space Shift in Long-Horizon Task*，基于LIBERO，以44原子技能评测单谓词变化、累积谓词变化和10条三技能链。原始任务顺序已知。环境将当前模拟状态传给下一技能环境，然后评测脚本覆盖机器人初始化姿态和速度切片；这一行为在BC和OpenVLA路径均存在，与本地论文§IV-E p.5一致。具体代码位置见[项目画像§3](01-boss-project.md)。[BOSS原文](https://arxiv.org/abs/2502.15679)

本报告区分三种问题：

1. **语义前置条件不成立**：例如后继要求空夹爪，前序却仍持物。需要执行门控、修复或重新选择前驱动作。
2. **物理入口不兼容**：谓词看似成立，但抓取位姿、接触、速度或可达性不适合后继。需要入口分布适应、连接动作或前驱优化。
3. **观测空间偏移**：任务仍可执行，前序改变的无关对象/关系使图像策略失效。需要视觉鲁棒性或适当数据覆盖；把场景恢复为旧样子可能撤销仍需要的成果。

这三类可能共存。仅凭“技能失败”无法区分；符号上不在当前Pre/Eff中的变量，也未必在真实接触动力学上无关。BOSS当前成功标志记录顺序完成事件，并没有在每个后继结束后重验全部历史成果；新评测应检查**仍需要保持的**谓词，而非要求所有历史谓词永久为真。[代码与数学审计](01-boss-project.md)

## 2. 文献怎样让前一个技能的状态被后一个利用

令前驱结束状态分布为 \(q_i^{end}(s)\)，后继在给定状态下、固定预算内成功的概率为 \(v_{i+1}(s)\)。相关量是

\[
H_{i\to i+1}=\mathbb{E}_{s\sim q_i^{end}}[v_{i+1}(s)],
\]

而不是两个技能各自在原始初始化分布上的成功率都高。对POMDP还需用观测历史或信念表示；图像相似并不保证可执行，动作预测相似也不证明物理等价。这是本报告的分析表达，不是某篇论文提供的通用保证。

已有方法大致做四件事，常常组合使用：

- **改变前驱和后继。** SCaR双向对齐终止与启动分布；Foresight用后继成功预测改造前驱残差奖励。前者有状态输入限制，后者主要证据来自单个三阶段仿真任务。[SCaR](https://proceedings.neurips.cc/paper_files/paper/2024/hash/ca92ff06d973ece92cecc561757d500e-Abstract-Conference.html)、[Foresight](https://arxiv.org/abs/2607.16506)
- **改变交接动作或目标状态。** DeCo预测下一技能入口并桥接，SPIN学习低物体扰动连接器，BATON用边界契约和剩余计划检索；CoRe通过反事实探测选择最小恢复集。因此“技能之间加桥接”“恢复时保护成果”都已有明确先例。[DeCo](https://arxiv.org/abs/2505.00527)、[SPIN](https://arxiv.org/abs/2502.18015)、[BATON](https://arxiv.org/abs/2608.16889)、[CoRe](https://arxiv.org/abs/2608.14822)
- **改变后继所见的表示。** Compose by Focus按任务构造相关对象/关系图；HODOR用对象/部件层级并保留全景冗余。二者都说明观测选择有价值，但不能从子任务得分或定性链演示推出随机长链的可靠率。[Compose by Focus](https://arxiv.org/abs/2509.16053)、[HODOR](https://arxiv.org/abs/2411.01284)
- **改变训练初态和组合数据。** SkillMimicGen把自由空间连接、启动增强与对象中心示范结合；RoCoDA已有阶段因果图和增强成功过滤。BOSS中RAMG的负结果仅约束其所测增强和模型，不能推出“数据增强普遍无效”。[SkillMimicGen](https://arxiv.org/abs/2410.18907)、[RoCoDA](https://arxiv.org/abs/2411.16959)、[BOSS项目画像§6](01-boss-project.md)

**现有实验证据支持“接口状态重要”，但没有给出任意技能组合、任意观测偏移下的可靠性保证。** 学习的成功评分存在泛化/校准误差；谓词契约依赖抽象完整性；软惩罚和采样规划也有模型与预算边界。这些限制应决定BOSS中比较什么，而不能用方法名称代替能力证明。

## 3. 最有用的实验结论及不可比之处

Foresight在同骨干的残差比较中，整任务从54.5±3.6%升到85.6±3.9%；DeCo同框架桥接姿态从0个变6个，成功率从34.1%升到66.7%。这比跨模型主表更直接支持衔接机制。[Foresight表II p.7](cards/P03-foresight.md)、[DeCo图7(c) p.7](cards/P08-deco.md)

SCaR的主要表格和Compose by Focus的组合分数都是**子任务完成进度**，不能把0.95或0.93读作95%或93%的完整链成功率。Semantic Handoff的clean/chained判定器与预算并非严格相同，诊断很有启发，但不能将差值完全因果归于handoff。[SCaR表1 p.8](cards/P07-scar.md)、[Compose证据卡](cards/P01-compose-focus.md)、[Semantic证据卡](cards/P05-semantic-handoff.md)

CoRe在LIBERO扰动表中π0.5从43.5%到88.2%，但恢复采用直接状态写入；81.9%的Arm-Only是抓取可行率加权估计。真正实体恢复证据另来自LangSwitch与真机，后者总计21/100到90/100。不能把仿真恢复上界、加权估计和真实恢复混在一个排行榜。[CoRe表2/3 p.5](cards/P15-core.md)

数据核查也保留了原文不一致：DeCo真机汇总写53.33%，逐项计数为45/90=50%；SPIN规划时间存在文表差异；SkillMimicGen初态增强附录的文字增益与表格不同。报告保留两者，不替作者选择“正确值”。[统一比较与核查表](03-comparison.md)

## 4. 复检后值得做什么

**优先方向是评测与数据贡献：建立BOSS的配对交接审计，区分视觉偏移、物理入口和必要成果破坏。** 它承接BOSS的优势，成本低于重训整个VLA，也能检验恢复方法的成功率到底来自什么。相关问题动机为E3；新审计的有效性仍为E0，窄组合新颖性仅N1。

第二方向是条件性方法假设：在真实交接状态上，以仿真验证的干预正负例监督门控，只对物理与任务条件确实兼容的干预施加策略一致性。它必须胜过同预算的阶段增强、真实交接数据和普通成功过滤，才能说明新增机制有价值。拟议机制/效果均E0，相关机制动机E1，新颖性N1。

不提出第三个凑数方向。“双向对齐”“后继成功奖励”“阶段因果增强”“保留成果的最小恢复”已被最近邻充分覆盖。**本次没有证据支持任何“首个解决Skill Handoff”的主张。** 具体反例、证据等级、最低实验和否定条件见[空白与创新](04-gaps-and-ideas.md)、[实验方案](05-experiments.md)。
