# 研究空白复检与候选创新点排序

截至2026-09-11。这里的方向是分析者提出的研究假设，不是作者结论，也不是已验证成果。最多保留两个；不为满足数量制造第三个。

## 1. 双轴证据标准

| 轴 | 等级 | 本报告的使用规则 |
|---|---|---|
| 问题/机制支持 | E3 | 多项独立直接实验支持同一**具体**问题或机制；不能由广泛问题支持推导新方法有效 |
| 同上 | E2 | 单项直接实验；同时记录数据集与协议边界 |
| 同上 | E1 | 间接证据、迁移依据或尚未隔离的机制解释 |
| 同上 | E0 | 新假设/新效果，尚无实验 |
| 新颖性复检 | N2 | 多源搜索并比较最近邻全文，对限定结论有较充分覆盖；不是法律/全领域新颖性保证 |
| 同上 | N1 | 局部覆盖；引用网络、近邻或后续版本仍可能改变结论 |
| 同上 | N0 | 未充分复检 |

保留方向的**整体新颖性均N1**。一些“已有工作已覆盖某机制”的撤销判断达到N2，但不能把这个N2移给尚未证实的新方案。

## 3. 候选方向 I1：BOSS 配对交接审计与反例数据

**建议优先级1，评测/数据贡献。**

**可证伪假设H1：**在固定后继、成功判定器和总动作预算下，视觉观测偏移、物理入口失配、仍有效成果破坏会造成可区分的失效模式；仅报单技能与历史整链成功率会隐藏至少一类差异，而配对审计能够稳定识别它，并改变对部分恢复机制的解释。

| 最近邻 | 已有能力 | 拟议增量，尚待验证 |
|---|---|---|
| BOSS | 无关谓词变体、累计变化、归位三技能链 | 实际交接快照、同源配对干预、仍需保持谓词的独立审计；分别记录reset前后 |
| Semantic Handoff | clean与chain失效诊断、入口模板 | 相同判定器/预算、同状态族配对，避免把judge差异当状态因果效应 |
| CoRe | 累计成果约束、最小反事实恢复 | 测量成功提升是否来自撤销成果、实体恢复成本；不把状态写入与实际恢复混报 |
| MoMaStage / Inverse Manipulation | 累积状态、保留已完成子任务、predicate fences | BOSS对象关系的可见/不可见与合法消解反例标签；不是重新发明保护集 |

**证据分级：**技能接口影响后继成功这一问题动机E3（Foresight、DeCo及其他独立实验）；BOSS具体三分审计的必要性/辨别能力E0；迁移依据E1；整体N1。不能把“发现静态代码未重验历史谓词”当成已经观察到虚假成功。

**接入与最低实验：**从现有CH3切换前后导出观测和仿真状态，在独立研究评测层回放；不改主算法API。先固定10条链，人工审核每个对象关系何时必须维持、何时允许消解。原始任务/CH1/CH2/CH3按原协议评估，另留出谓词组合。只做原策略、同预算重试、后继评分、义务审计、二者结合等小规模诊断对照；状态oracle仅离线评分。详见[实验方案](05-experiments.md)。

**资源与成本：**需要LIBERO资源、44技能checkpoint和可重放环境；不要求先训练VLA。首轮建议200条整链rollout（10链×总计20次，跨3评估seed分配7/7/6），至多产生400个成功前缀的自然边界快照，实际数量取决于前缀成功；再生成其配对变化。这是设计预算而非已采数据。一台能够评测现有BC的GPU主机和多CPU仿真为起点；无法在缺少本地权重/资源时承诺GPU显存、工时或吞吐。

**否定条件：**受控样本中没有足够可分离反例；新增指标不改变任何结论且对失效无辨别力；收益全来自额外重试；所谓视觉干预同时改变动力学且无法匹配；合法消解被频繁误报。出现这些结果，缩为复现/协议分析，不声称新benchmark必然必要。

## 4. 候选方向 I2：由真实交接正负例监督的干预有效性门控

**建议优先级2，在I1能够可靠生成标签后再决定是否实施。**

**可证伪假设H2：**对自然前驱终态进行候选谓词干预，以可达目标、短时接触/支撑后果和仍有效义务的仿真验证建立正负例；用它训练视觉门控，只在兼容正例上施加后继策略一致性，能在相同数据/交互预算下比“阶段增强＋交接数据＋普通成功过滤”更稳健地泛化未见谓词组合。

**机制区别必须具体：**RoCoDA已经阶段增强并过滤成功；CAIAC已经学习局部作用；AFP已经有相关性辅助损失；CoRe已经在推理时做反事实动作等价探测和最小恢复。因此这里的候选差异只可能是**来自真实交接的接触后验证标签、显式保留不应不变的负例，以及训练期门控目标**。把这些拼起来是否超过组合工程，尚无证据。接触后的短窗验证也不是整个长链的形式保证。

可考虑的研究目标（仅设计，不是实现）为

\[
L=L_{BC}+\lambda\,g_\phi(o,o',\ell,\text{phase})\,D(\pi_\theta(\cdot|o,\ell),\pi_\theta(\cdot|o',\ell))+\mu L_{gate}(g_\phi,y),
\]

其中 \(y\) 来自独立物理/任务验证，未知标签拒判；不能用“当前策略动作没变”自行生成全部真值。多模态成功动作不必逐帧相同，D需与策略分布匹配；若只用同噪声动作MSE，应明确它是代理。先在固定BC动作分布上定义损失，再考虑OpenVLA；不把一个未经定义的KL直接套在任意骨干。

**证据分级：**组合视觉问题E3；邻近增强/相关性机制支持E1；这一门控的正确性与效果E0；整体新颖性N1。

**接入与数据：**RAMG负责提出干预，实际回放重新采集状态；当前生成文件的旧`states`不可直接当新场景真值。将数据/标签放在独立旁路文件，骨干输入保持原RGB和已有本体信息。训练时状态oracle生成标签，测试时视觉门控不得读取状态；另报oracle上界。新增目标仅作为未来方案，不在本研究任务中修改训练脚本。

**最低对照：**原BC、RAMG、RoCoDA式阶段增强、阶段增强＋同预算交接数据、再加普通成功过滤、无门控一致性、门控无负例、完整门控、oracle门控。若无法在同一骨干实现RoCoDA原模型，用“RoCoDA启发的适配基线”命名，不声称复现原方法。

**资源：**先BC小范围验证，预设至少3训练种子，统一新增回放数；从单一骨干/部分场景起步后才扩44技能和OpenVLA。额外成本主要是干预重放、标签验证与门控训练；没有实测吞吐不估算GPU小时。推理门控必须单独记时，与训练只增强方法比较。

**否定条件：**普通成功过滤加同预算交接数据获得同等收益；门控只改善单技能、不改善组合偏移；oracle有效但RGB门控失效；负例误判破坏支撑/碰撞线索；收益只在训练组合成立；原任务显著退化或成本超过事先阈值。任何一种都不能被“增加更大模型”掩盖为已成功验证原假设。

## 5. 研究顺序与立项判断

先做I1能否产生可信且有区分度的标签，再做I2小范围消融。若I1无法区分失效来源，不应急于训练复杂模型。无重置物理衔接作为独立扩展，对照DeCo/SPIN/CoRe的实际恢复，不能通过改变基准协议制造原BOSS上的改进。

当前可以支持立项为“BOSS组合偏移的可归因交接评测与干预学习探索”；尚不足以支持“已证实的新handoff算法”。
